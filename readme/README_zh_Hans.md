## FFmpeg 工具集

**作者：** william-cai  
**版本：** 0.0.1  
**类型：** 工具

### 简介

FFmpeg 工具集是一个 Dify 插件，提供基于 FFmpeg 的强大媒体处理能力。目前包含视频拼接功能，未来将添加更多工具。

该插件让 Dify 中的 AI 智能体和工作流能够以编程方式处理视频内容，适用于以下场景：

- 将多个视频片段合并为一个无缝视频
- 从多个来源创建视频合集
- 自动化视频后期处理任务

### 功能特性

#### 视频拼接

将多个视频 URL 合并为单个视频文件。该工具接受视频 URL 列表，并按顺序将它们合并为一个输出视频。

**应用场景：**
- 将多个视频片段组合成完整视频
- 从剪辑片段创建视频蒙太奇
- 拼接录制的会话或直播流

### 配置说明

#### 前置条件

1. **FFmpeg**：本插件需要在插件运行环境中安装 FFmpeg。
   - Dify 云端版：FFmpeg 已预装，可直接使用。
   - 自托管 Dify：请确保 FFmpeg 已安装并在系统 PATH 中可用。

2. **Dify**：本插件需要 Dify 版本 0.0.1 或更高。

#### 安装方式

从 Dify 插件市场安装：

1. 进入你的 Dify 工作空间
2. 在工作空间设置中导航到 **插件**
3. 在市场中搜索"FFmpeg 工具集"
4. 点击 **安装**

或者从 GitHub 安装：

1. 克隆本仓库
2. 使用 Dify CLI 打包插件
3. 将 `.difypkg` 文件上传到你的 Dify 实例

### 使用说明

#### 视频拼接工具

视频拼接工具将多个视频合并为一个。

**参数说明：**

| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `video_urls` | string (JSON 数组) | 是 | 要合并的视频 URL 的 JSON 数组，按顺序排列。示例：`["https://example.com/video1.mp4", "https://example.com/video2.mp4"]` |
| `output_name` | string | 否 | 输出文件名（不含扩展名）。默认值：`merged_video` |

**使用示例：**

在 Dify 工作流或聊天流中，可以这样调用工具：

```json
{
  "video_urls": "[\"https://example.com/intro.mp4\", \"https://example.com/main.mp4\", \"https://example.com/outro.mp4\"]",
  "output_name": "final_video"
}
```

工具将返回一个合并后的视频文件，可在后续工作流步骤中使用或呈现给用户。

### 使用限制

- 所有输入视频应具有兼容的格式（编解码器、分辨率、帧率）以实现无缝拼接。格式不匹配可能导致播放问题。
- 工具按顺序处理视频，因此很长的视频或大量视频可能需要较长的处理时间。
- 输入视频必须通过 URL 可访问（公开 URL 或 Dify 服务器可访问的 URL）。
